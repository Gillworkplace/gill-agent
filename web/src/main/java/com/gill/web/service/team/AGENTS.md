# 团队纯领域策略

此目录不访问数据库、网络或 Spring 事务。`TeamEngine` 为路由；定义、通信、运行和版本策略依赖更下层的快照、权限与数据辅助工具，不互相循环调用。

可信 actor 来自 Java 认证或租约任务，不接受模型提供身份。跨团队、人工专属配置、未解决决定、未知动作和版本竞争必须在服务端拒绝。修改运行配置不得热改历史任务快照。

TaskFlow为更低层依赖/调度规则，由策略与TeamService向下复用；不反调策略、数据库或网关。通知的@不等于派工；旧generation不能执行新动作，旧决定不能复活取消/改派任务。等待依赖阻断后继，有效上级评估分支和事先声明独立的任务继续。未知在途结果照实保留，不能被决定答复或恢复覆盖。

通知、核查与正式派工按 D40 分开。派工许可仅由用户为新工作启用并显式授予，正式派工入口统一校验工作项许可与当前依赖。核查可收集意见，核查的来源仍约束其正式派工。

持久化和执行入口见 web/README.md、专题 implementation.md。有效运行政策为主需求 D38/P01～06。
