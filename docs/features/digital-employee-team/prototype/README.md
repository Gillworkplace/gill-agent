# 通用数字员工团队：快速交互原型 v0.3

日期：2026-11-17。依据：[基础设施需求分析 v0.3](../requirement_analysis.md)及用户本轮反馈：对话为核心、团队状态在右侧、模板支持对话生成、“概览”改名“工作台”。

## 打开与体验

直接用浏览器打开 [index.html](index.html)，无需安装、构建或连接后台。本机预览：[工作台](http://127.0.0.1:4173/?v=0.3#/overview)、[数字员工模板](http://127.0.0.1:4173/?v=0.3#/templates)。带版本参数的链接和资源用于避免旧原型缓存。

主导航为**工作台 / 数字员工模板 / 团队**：

1. **工作台**：左侧主要空间展示当前团队群聊和输入框；右侧集中展示各团队的状态、空闲人数、进展和 @我 提示，点击切换群聊。取消聊天左侧团队列表和重复的第三栏摘要；当前团队详情从右栏按需打开。手机使用右侧团队状态抽屉。
2. **数字员工模板**：点击“对话创建模板”，先聊工作目标和能力，再通过多轮对话补充要求、调整名称和 Skills；旁边预览草稿，也可直接编辑名称和工作 Prompt。点击“保存为数字员工模板”后才进入模板库，随后可管理每个 Skill 或为团队创建员工。手机草稿位于对话下方，可展开查看。
3. **团队**：查看各团队专属员工、分工、模板来源和直属上级；从模板创建员工，团队流程 Prompt 按需展开。

模板可复用，实际员工不跨团队。@我的问题在群聊处理，不设置独立的运行记录或我的待办页面；内部事实能力仍由需求保留。`#/overview` 仅是兼容既有链接的路由，界面名称已统一为“工作台”。

## 模拟范围与未决事项

- 全部为隔离的静态 HTML/CSS/JavaScript 和合成数据，无框架、CDN 或新增依赖。没有改动 Vue 业务界面、后台、数据库或现有服务。
- 对话生成使用本地预置逻辑，保留各轮用户原文并更新演示草稿，**没有连接真实模型**。员工工作、状态和反馈同样为演示，不构成真实执行或能力验证。
- 对话草稿未经保存不进入模板库；保存时保留对话来源。保存模板不自动创建实际员工，员工仍须由用户在指定团队明确创建。
- 草稿可以直接编辑，继续对话保留已有修改；Skills 保存后可逐项编辑。读过 @消息不等于决定，配置建议仍由用户明确采纳。
- 已有员工展示创建时的模板、Prompt 与 Skills 快照。模板同步既有员工仍属 Q-07；层级、等待及在途生效仍待 Q-02～04。本原型不自动决定这些政策。
- 空团队收到目标仅保留消息并提示创建员工，不生成工作中任务。

## 实际轻量走查

本版使用 Chrome 进行实际 DOM 点击和截图，覆盖 1440×1040、1080×980 桌面及 390×844 手机视口：

- 工作台名称、宽对话主区和右侧团队状态两栏；紧凑桌面仍保留右栏，点击切换团队后群聊更新，详情按需展开。
- 模板对话入口、三轮连续对话、修改名称及增加 Skill、保留前轮要求、直接编辑草稿后继续对话。
- 保存前模板数量不变；明确保存后生成模板并保留七条对话来源，没有自动创建员工。
- 手机右侧团队抽屉、切换后收起；模板对话输入可用，草稿可展开并保存，返回对话自动滚至最新消息；没有横向页面溢出。
- 走查未观察到脚本异常。此记录是原型可操作性走查，不是完整测试、真实模型/接口验证或业务验收。v0.2 对既有员工归属、Skills 编辑和 @我决定的历史走查不冒充本轮全量重测。
