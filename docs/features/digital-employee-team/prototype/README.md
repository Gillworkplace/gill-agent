# 通用数字员工团队：快速交互原型 v0.2

日期：2026-11-17。依据：[基础设施需求分析 v0.2](../requirement_analysis.md)、产品目标 D18～D26，重点落实用户对 v0.1 的简化反馈。

## 打开与体验

直接用浏览器打开 [index.html](index.html)，无需安装、构建或连接后台。本机预览：[打开概览](http://127.0.0.1:4173/#/overview)。全部为同目录 HTML/CSS/JavaScript，无 CDN 或新增依赖。

主导航仅保留三个入口：

1. **概览**：团队列表显示进展、工作/等待/空闲状态与 @我 提示；选择团队进入群聊。直接发送目标、查看本团队产物、展开上报经过、引用并回复问题，或决定是否采纳员工建议。手机通过“切换团队”按钮打开列表，进展与成员可从群聊顶部详情展开。
2. **数字员工模板**：用 Prompt 生成可编辑模板草案，管理工作 Prompt 及 Skills 的名称、用途和具体内容；从模板为指定团队创建新员工。
3. **团队**：查看各团队专属员工、主要分工、模板来源和直属上级；创建团队及员工。团队流程 Prompt 按需展开。

不再设置独立运行记录、我的待办或工具顶级页面。进展与 @我的问题留在群聊；旧原型的运行/待办地址会回到概览。模板可复用，实际员工不可跨团队：相同模板在两个团队创建的是不同身份，每个员工只有一个 `teamId`。

## 模拟范围与未决事项

- 所有员工、资料、任务、状态、消息和提交结果都是本地合成演示，只保存在浏览器内存；刷新或“重置演示”恢复初始内容。没有改动现有 Vue 业务界面或服务。
- 模板“生成”使用预置内容保留用户描述，不调用真实模型。群聊回复与进展反馈也为模拟，没有真实执行、后台、数据库或外部业务系统。
- 打开或阅读 @我 消息不会产生用户决定。员工只提出配置建议，用户明确采纳后才保存模板新版本。
- 员工展示创建时的模板、Prompt 与 Skills 快照。模板更新如何同步既有员工仍属 Q-07；本原型不自动覆盖已有员工，不能据此确定正式同步策略。
- 单一直属上级用于演示逐级上报；关系异常、多上级、等待范围和在途版本生效仍待 Q-02～04 细化。没有增加全阶段审批或固定业务流程。
- 新建团队没有成员；向空团队发送目标仅保留消息并提示先创建员工，不伪报已开始执行。

## 实际轻量走查

Chrome 实际 DOM 点击和截图覆盖 1440×1040 桌面及 390×844 手机视口，已观察：

- 三入口、旧地址回到概览、团队切换、进展与空闲提示、@我过滤、上报经过、群聊引用回复及建议的显式采纳。
- 模板生成和保存、工作 Prompt 保存、Skill 添加/编辑/删除；模板变更保留已有员工的创建快照。
- 同一模板在不同团队创建不同员工、上级选项只包含本团队员工或用户、新团队不复制旧成员和证据。
- 手机主导航和团队列表的打开、切换与关闭；页面无横向溢出，走查未观察到脚本异常。

产品评估发现的空团队伪报工作中问题已修正，已实际复看目标消息保留、任务为空、待创建员工提示及创建入口。以上是原型可操作性走查，不是完整测试、真实接口验证或业务验收。
