# 通用数字员工团队：快速交互原型 v0.4

日期：2026-11-17。依据：[基础设施需求分析 v0.4](../requirement_analysis.md)。本轮增加团队项目库、项目文档归档与版本查看、同团队多需求并行的版本管理演示，并将团队首页改为摘要卡片、详情内管理；沿用工作台对话核心和三个主入口。

## 打开与体验

浏览器直接打开 [index.html](index.html)，无需安装、构建或后台。本机预览：[工作台](http://127.0.0.1:4173/?v=0.4#/overview)、[研发团队项目库](http://127.0.0.1:4173/?v=0.4#/library/dev)。版本参数用于避免旧资源缓存。

主导航仍为**工作台 / 数字员工模板 / 团队**：

- **工作台**：群聊占主要区域，右侧展示团队状态和切换；当前团队项目库可从右侧打开。消息中的问题、决定及现有对话交互仍保留。
- **数字员工模板**：多轮对话生成和修改模板草稿，预览并明确保存后，再为团队创建专属员工；模板可复用，实际员工不跨团队。
- **团队 → 项目库**：每个团队都有自己的项目库，可创建多个项目；团队首页只展示负责项目、产品/模块描述、状态、员工数和项目数，点击进入详情后可编辑简介、管理员工及项目库；项目按团队归属组织，不另增一级菜单。

项目内分三个页签：

1. **文档归档**：归档项目文档、打开具体版本、追加新版本并保留旧内容；文档可关联具体需求。
2. **并行需求**：在同一项目建立多条需求，分别展示负责人、所用基线、文档版本、工作分支及独立执行空间。创建需求不创建或跨团队调动员工。
3. **版本管理**：查看主线及需求分支、检查演示变更与冲突、预览集成及历史。一个需求集成不静默修改其他需求的基线；出现示例冲突时不能直接当作成功集成。

业务项目可只归档资料，不要求绑定代码仓库；没有把所有团队任务限定为软件研发或强制固定流程。

## 模拟范围和未决事项

- 全部为隔离的静态 HTML/CSS/JavaScript 与合成数据，无真实模型、后台或数据库；刷新/重置恢复演示内容，没有修改现有 Vue 业务界面或服务。
- 文档内容与版本只存在浏览器内存，不上传或改写真实项目文件。所有分支、工作空间、检查、冲突和集成均为**本地模拟**，没有执行 Git，也没有连接仓库或检查真实代码。
- 文档版本、需求所用版本和集成历史分别保留。保存模板不自动创建员工，读过 @我 消息不产生决定，空团队不会伪报执行工作。
- Git 工具服务商/接入、项目与仓库映射、合并授权及冲突处理政策仍待技术设计和业务细化；本原型的按钮和样例不决定正式权限或验证规则。
- 模板同步既有员工、上下级异常、等待范围、在途版本采用等既有开放事项继续保留。

## 轻量实际走查与评估

Chrome 实际 DOM 点击和截图覆盖 1440×1040 桌面及 390×844 手机视口，已观察：

- 团队首页无员工名单或员工创建按钮；卡片展示项目名称、产品/模块描述和实际人数，详情可编辑简介、管理员工和进入项目库。
- 团队项目库隔离、新建空项目、业务项目不要求 Git；工作台入口跟随当前团队。
- 查看文档旧版、追加新版和来源需求，原文及既有需求的文档快照保留；新需求引用当前项目和文档基线。
- 两项需求的分支及工作空间标识独立；某需求保存版本不串改另一需求；示例冲突无继续集成入口；明确模拟集成保留历史且不自动更新其他需求基线。
- 手机团队摘要、项目/并行需求页面和需求详情抽屉可用，无横向页面溢出。
- 走查发现并修正新增模块脚本引用遗漏，修正后上述关键路径未观察到脚本异常。这不是完整测试或真实 Git/接口验证；没有重做与本次无关的全部 v0.3 路径。
