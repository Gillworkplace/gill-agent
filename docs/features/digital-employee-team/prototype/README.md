# 通用数字员工团队：快速交互原型 v0.5

日期：2026-11-17。依据：[基础设施需求分析 v0.5](../requirement_analysis.md)。本轮按用户最后的替代方案收敛：**知识库对员工只读，员工模板可自迭代**；知识挂载对象为实际员工，所有已挂载员工可见共享源更新。

## 打开与体验

直接在浏览器打开 [index.html](index.html)，无需安装、构建或后台。本机入口：[知识库](http://127.0.0.1:4173/?v=0.5#/knowledge)、[研发团队员工知识](http://127.0.0.1:4173/?v=0.5#/employee-knowledge/dev)、[模板自迭代](http://127.0.0.1:4173/?v=0.5#/template/verify)。版本参数避免旧资源缓存。

主导航为**工作台 / 数字员工模板 / 团队 / 知识库**，保留群聊主区、右侧团队状态与团队首页摘要：

- **知识库**：新增共享知识源、由用户追加修订版、查看历史和挂载员工。员工只能查阅挂载内容，不能写知识或自行修改挂载。每次修订形成新版本，历史内容保留。
- **团队详情 → 员工知识**：逐员工查看和管理挂载；员工详情也可直接进入。此页面只是当前团队员工的汇总，保存挂载关系使用 employeeId，没有团队级绑定、全队继承或新员工默认继承。
- **共享源**：同一知识可由不同团队中的员工显式挂载。用户修订源后，所有已挂载员工可见最新版本，未挂载员工不获得该知识；不改变员工所属团队或项目隔离。
- **数字员工模板 → 自迭代演示**：选择本轮演示员工，调整工作 Prompt 与 Skills，保存为模板新版本；查看理由、员工来源和旧版本。用户后续编辑同样进入模板历史。
- 工作台、对话创建模板、团队成员和项目库/并行需求继续保留，不把知识挂载或模板迭代当成新增员工或真实项目执行。

## 最新规则与模拟范围

- 用户已用“知识库不可变、员工模板可变”替代本轮早先的“知识有两类”设想。这里的知识只读沿用此前 Agent 不可修改的语境：用户可维护修订，员工不可写，已保存历史版本不原地改写。模板 Prompt/Skills 允许员工自迭代，覆盖先前员工只能建议模板变更的限制。
- 新增员工、调整团队流程及员工知识挂载的权限未因此放宽。原型中模板迭代选择使用该模板的员工以展示来源，这不是所有模板写入权限的技术定稿。
- 共享源“最新可见”、员工创建时的模板快照和实际工作采用版本分开。模板迭代保留旧快照并显示最新可用版，不声称已静默切换现有员工或在途工作；实际采用与并发规则仍待设计。
- 所有知识、挂载、模板迭代及历史都是浏览器内存中的合成演示。迭代表单手工输入模拟结果，未调用模型、检索、RAG 或后台；不证明真实 Agent 已完成自迭代或服务端权限验证。
- 刷新/重置恢复示例。未改现有 Vue 服务、数据库、真实知识或 Git；没有添加依赖。项目库与版本工具仍属 v0.4 的本地模拟。

## 轻量实际走查

Chrome 实际 DOM 点击和截图覆盖 1440×1040 桌面与 390×844 手机：

- 四入口、员工知识汇总、员工详情挂载入口，全部知识均为员工只读，没有可自迭代知识分类或入口。
- 用户修订保存旧版；跨团队已挂载员工可见新版；查看历史不改变共享源。未挂载同事和新员工不会继承挂载。
- 单员工保存只改该员工；知识源管理可显式选择跨团队员工；员工写入知识或改变挂载被模拟写入接口拒绝，过期版本提示且不覆盖。
- 员工模板 Prompt/Skills 自迭代保存版本、理由和来源，旧版本可追溯；不修改员工创建快照、知识库或其他模板。后续用户编辑也保留历史，过期模板写入拒绝覆盖。
- 新增知识源记录用户来源且不自动挂载；通过对话新建模板纳入统一版本历史，无实际员工的模板也有演示来源说明。
- 手机知识页、员工知识页、挂载及模板迭代弹窗无横向溢出。上述走查未观察到脚本异常；不等同完整测试、真实模型运行或服务端鉴权验证。
