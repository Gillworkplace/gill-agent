# 通用数字员工团队：快速交互原型 v0.6

日期：2026-11-17。依据：[基础设施需求分析 v0.6](../requirement_analysis.md)及 D35。用户要求在团队内用树管理层级，并支持拖拽；本轮同时完成[产品与系统联合评审](../requirement_review.md)。

## 打开与体验

直接打开 [index.html](index.html)，无需安装、构建或后台。本机预览：[研发团队组织树](http://127.0.0.1:4173/?v=0.6#/team/dev)、[业务团队](http://127.0.0.1:4173/?v=0.6#/team/biz)。版本参数用于避免旧资源缓存。

团队详情的“团队成员”页改为组织树与节点详情：

- 以“我”为最终汇报根，员工节点显示姓名和开放的岗位分工；本版以单直属上级演示，不固定岗位或层数，不将该形式推成全部平台组织规则。
- 点击节点查看或编辑直属上级及本团队分工。可从详情进入员工配置和知识挂载。
- 拖动员工到另一位员工下面调整上级；拖到根节点可设为直接向你汇报。不会移动员工所属团队，也不修改模板 Prompt。
- 拖动或表单先修改组织草稿。支持撤销一步、重新读取和保存层级；保存前不改变源关系，源关系或成员变化时不覆盖新内容。
- 拒绝自身、后代、跨团队或无效上级；缺失、循环关系显式列为待修复，不自动归根。空团队保留从模板创建员工的入口。
- 手机上保留树形查看和选择上级/保存的替代操作；未声称触屏拖拽已完成验证。

上下级树用于逐级评估与上报，监督关系独立，也不据此固定任务执行顺序。工作台、对话模板、自迭代历史、员工只读知识、团队项目库和并行版本等既有演示继续保留。

## 本地演示与评审边界

全部为静态 HTML/CSS/JavaScript 和浏览器内存中的合成数据；刷新/重置恢复初始状态，没有接后台、真实模型或数据库，也没有更改生产服务。

保存只更新本地团队关系与分工，未实现服务端校验、组织历史持久化或在途工作采用新层级。旧知识/模板/Git 的模拟边界仍适用。

本轮联合评审认为产品方向合适，可以进入系统设计；模板采用、监督/升级等待恢复、知识派生内容共享、自主运行停止条件及真实运行隔离/恢复仍需补全。组织树补齐了配置交互，不能据此认定整体可直接开发。

## 实际轻量走查

Chrome 覆盖 1440×1040 桌面和 390×844 手机视口：

- 用实际鼠标输入触发原生拖拽并传递浏览器拖拽事件，观察同队移动、拖到根节点及拖到下级被拒绝。
- 验证拖动仅改草稿、撤销/重新读取、表单替代、保存关系与分工、模板和团队归属保持、过期源拒绝覆盖。
- 核对自身/跨队校验、缺失关系显示与修复、手机树无页面横向溢出、手机选择上级保存及空团队出口。
- 走查未观察到脚本异常；这是原型关键路径检查，不是全量测试、真实组织服务或模型运行验证。
