# 通用数字员工团队：快速交互原型 v0.1

日期：2026-11-17。依据：[基础设施需求分析 v0.1](../requirement_analysis.md)，产品目标 D18～D23。

## 打开与体验

直接用浏览器打开 [index.html](index.html)，无需安装、构建或连接后台。当前本机预览地址为 [http://127.0.0.1:4173](http://127.0.0.1:4173)。CSS、JavaScript 均为同目录静态资源，无 CDN 或新增依赖。

建议先体验三条路径：

1. **生成员工和团队**：数字员工 → 生成员工 → 输入 Prompt → 查看、调整并保存；团队与流程 → 用 Prompt 组建团队 → 调整员工数量和内容 → 采用 → 查看或编辑上下级关系、流程 Prompt。
2. **管理团队运行**：概览 → 描述目标并选择团队 → 交给团队 → 查看协作动态、当前安排、员工沟通、产物与核查；可演示重规划、补充指令和暂停/继续。
3. **只处理需要自己的决定**：我的待办 → 查看方案取舍的逐级评估 → 提交决定或要求补证；打开员工调整建议 → 修改后采纳或拒绝。

研发与业务团队都是示例配置。岗位、人数、工作目标与方法不被这两套示例限定；新增团队运行不借用其他运行的产物或核查证据。

## 模拟范围与设计假设

- 所有员工、资料、生成内容、任务、消息、检查和提交结果均为本地合成数据，仅在浏览器内存中变化；刷新或“重置演示”会恢复初始内容。
- “生成”使用可编辑的预置内容保留用户输入，未调用真实模型；工具连接、执行、真实数据库和业务系统均未接入。没有改动现有 Vue 业务界面或服务。
- 展示单一直属上级及可编辑关系，属于 Q-03 的演示方案，不代表多上级及异常关系处理已定稿。
- 暂停和继续展示控制反馈；暂停期间提交决定只记录决定并保持暂停，明确继续后才切换演示状态。升级等待范围和在途外部动作如何停止仍属 Q-02。
- 保存员工或流程新版本仅演示配置管理；在途运行采用新版的方式仍属 Q-04，不以原型静态效果确定。
- 监督示例展示具体版本、问题、修正与复核；未设全阶段审批，也未把所有未关闭问题都固定为整体交付阻断项。权限细节仍属 Q-01。
