## 复现

从仓库根运行：

```sh
agent/.venv/bin/python -m unittest discover -s agent/tests -v
npm --prefix web/frontend test
npm --prefix web/frontend run typecheck
npm --prefix web/frontend run build
mvn -f web/pom.xml test
```

最后一项要求 Java21；真实数据库测试另外设置 `GILL_TEAM_DB_TEST=1`、独立 `DB_URL` 与凭据。所有测试用户以 team-it- 前缀创建并按 owner 清理；禁止将此测试连到用户业务库。真实模型验收须先具备可用资源，凭据只进本地环境文件。
